# QtPreved

Linux-аналог PuntoSwitcher для KDE Plasma на Wayland.

Название — это "Привет, Qt!" набранный не в той раскладке.

## Логика разбиения на слова

Слово завершается (и запускается анализ) при вводе любого из стоп-символов:

**Стоп-символы:** пробел, Enter, Tab, `. , ! ? ; : - ( ) [ ] { } "`

**Не являются стопом** (считаются частью слова): `'` (апостроф — для `don't`), `_`, `@`, `/`, `\`

**Сброс буфера без анализа:** Escape, любая комбинация с Ctrl или Alt (пользователь переключился на другое действие)

Backspace убирает последний символ из буфера.

## Что делает

Работает фоновым процессом и следит за тем, что вы печатаете. Если слово набрано не в той раскладке — исправляет автоматически или по нажатию горячей клавиши.

### Автоматическое переключение

После завершения слова (пробел, Enter) программа анализирует набранный текст. Если слово выглядит как бессмыслица в текущей раскладке, но имеет смысл в другой — автоматически удаляет слово и перепечатывает его в правильной раскладке. Алгоритм использует частотный анализ биграмм и список частых слов.

Пример: напечатали `ghbdtn` в английской раскладке — программа исправит на `привет` и переключит раскладку на русскую.

### Ручное переключение

Нажатие `Pause` (настраивается) переключает текущее слово в другую раскладку и перепечатывает его. Работает в любой момент, не дожидаясь пробела.

### Конвертация выделенного текста

Выделить любой текст мышкой или клавиатурой, нажать горячую клавишу — весь выделенный фрагмент будет перепечатан в другой раскладке. Удобно для исправления больших кусков текста.

### Отмена последнего переключения

Отдельная горячая клавиша отменяет последнее автоматическое или ручное переключение и возвращает исходный текст.

### Исключения

- **Слова** — список слов, которые не нужно трогать (аббревиатуры, технические термины: `OK`, `PDF`, `Linux`, ...)
- **Приложения** — в терминале, IDE и других указанных приложениях автопереключение не работает (постоянно, сохраняется в конфиг)
- **Текущее окно** — горячая клавиша временно отключает/включает работу для активного окна, не затрагивая другие окна того же приложения; сбрасывается при закрытии окна

## Технический стек

**Прототип:** Python 3 + PyQt6  
**Целевая версия:** C++ + Qt6

Работает на уровне ядра через `evdev` (чтение клавиатуры) и `uinput` (инжект нажатий), поэтому не зависит от X11 или Wayland — работает в обоих.

Переключение раскладки через KDE DBus (`org.kde.keyboard`).

## Поддерживаемые раскладки

EN ↔ RU (стандартная ЙЦУКЕН / QWERTY)

## Установка

> Раздел будет дополнен после первого релиза.

```bash
# Зависимости
sudo dnf install python3-evdev python3-pyqt6

# Добавить себя в группу input (нужен перелогин)
sudo usermod -a -G input $USER

# Запуск
python3 main.py
```

## Настройки

Конфиг хранится в `~/.config/qtpreved/config.json`.

Настраивается через графический интерфейс (иконка в трее → Настройки):

- Горячая клавиша для ручного переключения текущего слова
- Горячая клавиша для конвертации выделенного текста
- Горячая клавиша для отмены последнего переключения
- Горячая клавиша для временного отключения/включения для текущего окна
- Порог чувствительности автодетекта
- Список слов-исключений
- Список приложений-исключений (постоянные исключения)
- Автозапуск с KDE

## Идеи для развития

- **Авто-исправление регистра** — если слово набрано в хаотичном регистре (`пРиВеТ`), привести к нормальному виду
- **Транслитерация** — `privet` → `привет` без смены раскладки
- **Обучение** — если пользователь отменил переключение, автоматически добавить слово в исключения
- **Статистика** — сколько раз переключал, топ слов-ошибок
- **Другие пары раскладок** — DE, UK, FR и т.д.
- **Конвертация буфера обмена** — преобразовать содержимое clipboard
